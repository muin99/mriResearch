QUICK START WORKFLOW:
================================================================================

STEP 1: Install Dependencies
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
   pip install -r requirements_training.txt

STEP 2: Verify Dataset
   - Ensure 'breast_mri_dataset' folder exists
   - Structure: Benign/ and Malignant/ folders with augmentation subfolders

STEP 3: Run Training
   python train_complete_model.py

STEP 4: Check Results
   - All outputs in 'training_results' folder
   - Visualizations in 'training_results/plots'
   - Metrics in 'training_results/tables'
   - Best model in 'training_results/models'
