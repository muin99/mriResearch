================================================================================
ONE COMMAND TO RULE THEM ALL
================================================================================

Just run this in your terminal/command prompt:

    python setup_and_run.py

That's it! The script will:
1. ✅ Install all required libraries automatically
2. ✅ Set up PyTorch with CUDA support
3. ✅ Verify everything is installed correctly
4. ✅ Ask if you want to explore the dataset (optional)
5. ✅ Run the main training script (2-4 hours)

================================================================================

================================================================================

If you're on Windows, you can also:

1. Double-click: setup_and_run.bat

OR

   setup_and_run.bat

================================================================================
WHAT HAPPENS
================================================================================

STEP 1: Installation (15-30 minutes)
   - Upgrades pip
   - Installs PyTorch (with CUDA if available)
   - Installs all other libraries
   - Verifies installation

STEP 2: Optional Dataset Exploration (1-5 minutes)
   - Shows dataset structure
   - Creates sample visualizations

STEP 3: Training (2-4 hours)
   - Trains the model
   - Generates 16 visualizations
   - Creates all metrics tables
   - Saves trained model

================================================================================
REQUIREMENTS
================================================================================

✓ Python 3.8 or higher installed
✓ pip (comes with Python)
✓ Internet connection (for downloading packages)
✓ ~5-10 GB free disk space (for packages and dataset)

================================================================================
IF SOMETHING GOES WRONG
================================================================================

1. Check Python is installed:
   python --version

2. Check pip is installed:
   python -m pip --version

3. If scripts fail, see: INSTALL_AND_RUN.txt

4. For manual installation, see: INSTALLATION_GUIDE.txt
