================================================================================
INSTALLATION GUIDE - BREAST MRI TRAINING SCRIPT
================================================================================

STEP 1: INSTALL PYTHON
-----------------------
- Python 3.8 or higher is required
- Check your Python version: python --version
- If not installed, download from: https://www.python.org/downloads/

STEP 2: INSTALL CUDA (FOR GPU SUPPORT)
--------------------------------------
Your RTX 3050 6GB requires CUDA for GPU acceleration:

1. Check CUDA version compatibility:
   - RTX 3050 supports CUDA 11.0 and higher
   - Recommended: CUDA 11.8 or 12.1

2. Download CUDA Toolkit from:
   https://developer.nvidia.com/cuda-downloads

3. Download cuDNN (if needed):
   https://developer.nvidia.com/cudnn

STEP 3: INSTALL PYTORCH WITH CUDA
----------------------------------
Install PyTorch with CUDA support:

For CUDA 11.8:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

For CUDA 12.1:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

For CPU only (NOT RECOMMENDED - will be very slow):
pip install torch torchvision torchaudio

Verify installation:
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"

STEP 4: INSTALL ALL OTHER REQUIREMENTS
----------------------------------------
pip install -r requirements_training.txt

Or install individually:

# Core packages
pip install numpy>=1.24.0
pip install pandas>=2.0.0
pip install Pillow>=10.0.0
pip install opencv-python>=4.8.0

# Machine Learning
pip install scikit-learn>=1.3.0
pip install scikit-image>=0.21.0

# Visualization
pip install matplotlib>=3.7.0
pip install seaborn>=0.12.0
pip install plotly>=5.17.0

# Utilities
pip install tqdm>=4.65.0

Run this Python script to verify all packages:

STEP 7: RUN TRAINING
--------------------
python train_complete_model.py

TROUBLESHOOTING
---------------

Problem: "CUDA out of memory"
Solution:
- Reduce batch_size in CONFIG (try 8 or 4)
- Reduce image_size (try 128 or 192)
- Enable gradient_accumulation_steps
- Close other GPU applications

Problem: "ModuleNotFoundError"
Solution:
- Install missing package: pip install <package_name>
- Check requirements_training.txt

Problem: "CUDA not available"
Solution:
- Verify CUDA installation: nvidia-smi
- Reinstall PyTorch with CUDA support
- Check GPU drivers are up to date

Problem: "Dataset not found"
Solution:
- Check dataset path in CONFIG
- Ensure folder structure is correct
- Verify images are in .jpg, .png, or .jpeg format

PERFORMANCE OPTIMIZATION FOR RTX 3050 6GB
------------------------------------------
The script is already optimized, but you can further adjust:

1. Batch size: 16 (current) - reduce to 8 if OOM errors
2. Image size: 224 (current) - reduce to 128 for faster training
3. Mixed precision: Enabled (saves memory)
4. Gradient accumulation: 2 steps (effective batch size = 32)
5. Number of workers: 4 (adjust based on CPU cores)

ESTIMATED TRAINING TIME
-----------------------
- With RTX 3050 6GB: 2-4 hours for 100 epochs
- Training will stop early if validation doesn't improve (patience=15)
- Checkpoints saved every 10 epochs
