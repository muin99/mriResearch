QUICK START GUIDE - TRAINING SCRIPT
================================================================================

QUICK INSTALLATION (3 STEPS):
-----------------------------
1. Install PyTorch with CUDA:
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

2. Install other requirements:
   pip install -r requirements_training.txt

3. Run training:
   python train_complete_model.py

WHAT THE SCRIPT DOES:
---------------------
✓ Loads dataset from 'breast_mri_dataset' folder
✓ Splits data: 70% train, 15% validation, 15% test
✓ Trains ResNet18 model for 2-3+ hours (100 epochs max)
✓ Saves best model automatically
✓ Generates 8+ research-grade visualizations
✓ Creates comprehensive metrics tables
✓ Saves all results to 'training_results' folder

CONFIGURATION (in train_complete_model.py):
-------------------------------------------
CONFIG = {
    'batch_size': 16,           # Adjust if GPU memory issues
    'num_epochs': 100,          # Maximum epochs
    'learning_rate': 0.001,     # Initial learning rate
    'patience': 15,             # Early stopping patience
    'image_size': 224,          # Input image size
}

TRAINING TIME:
-------------
- Expected: 2-4 hours on RTX 3050 6GB
- Early stopping if no improvement (saves time)
- Checkpoints every 10 epochs (resume if needed)

MONITORING:
-----------
The script prints:
- Training progress with progress bars
- Loss and accuracy each epoch
- Best model saves automatically
- Final test set metrics

TIPS:
-----
✓ Let it run - training takes time but is fully automated
✓ Check 'training_results/plots' for visualizations
✓ Best model saved automatically when validation improves
✓ Can stop early (Ctrl+C) - best model already saved
✓ Resume from checkpoint if needed (modify script)

TROUBLESHOOTING:
---------------
Memory Error? → Reduce batch_size to 8 or 4
CUDA Error? → Check CUDA installation (see INSTALLATION_GUIDE.txt)
Dataset Error? → Check folder structure matches expected format
